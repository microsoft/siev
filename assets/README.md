# Assets

This directory contains visual assets used in the SIEV project documentation.

## Structure

- `figures/` - Contains SVG figures and charts used in README.md and documentation
  - Model comparison radar charts
  - Performance visualization graphics
  - Research result illustrations

## File Naming Convention

Files follow the pattern: `{type}_{description}_{model1}_vs_{model2}.svg`

Example: `two_model_radar_comparison_GPT-41-mini_vs_GPT-41.svg`

## Usage

These assets are referenced in the main README.md and other documentation files. When adding new visual assets, please follow the established naming conventions and place them in the appropriate subdirectory.
