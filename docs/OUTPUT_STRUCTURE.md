# SIEV Output Structure Guide

This document describes the complete output structure generated by SIEV evaluations.

## 📁 Directory Structure

After running an evaluation, your experiment directory will contain:

```
data/experiments/your-experiment-name/
├── all_responses.json              # Complete dialectical conversations
├── evaluation_results_attempt_1.json  # Statistical metrics  
├── summary_aggregate.json          # Aggregated cross-dataset results
├── comparison_chart.png           # Basic performance comparison
├── response_0.json                # Individual question responses
├── response_1.json
└── ...
```

## 📊 Core Output Files

### 1. `all_responses.json`
**Purpose**: Complete record of all dialectical conversations

**Structure**:
```json
{
  "0": {
    "question": "Question text",
    "answer": "Correct answer", 
    "thesis": "Initial model response",
    "thesis_answer": "Extracted thesis answer",
    "antithesis": "Critical review/challenge",
    "antithesis_answer": "Extracted antithesis answer", 
    "synthesis": "Final refined response",
    "synthesis_answer": "Extracted synthesis answer"
  }
}
```

### 2. `evaluation_results_attempt_1.json`
**Purpose**: Statistical analysis and accuracy metrics

**Structure**:
```json
{
  "thesis_accuracy": 0.75,
  "synthesis_1_accuracy": 0.80,
  "dialectical_score_1": 0.05,
  "total_questions": 100,
  "thesis_correct": 75,
  "synthesis_1_correct": 80
}
```

### 3. `summary_aggregate.json`
**Purpose**: Cross-dataset aggregated statistics

**Structure**:
```json
{
  "weighted_thesis_accuracy": 0.72,
  "weighted_synthesis_accuracy": 0.78,
  "weighted_dialectical_score": 0.06,
  "total_weight": 200,
  "dataset_breakdown": {
    "gsm": {...},
    "mmlu": {...}
  }
}
```

### 4. Individual Response Files
**Purpose**: Detailed per-question dialectical conversations

**Files**: `response_0.json`, `response_1.json`, etc.
**Structure**: Same as entries in `all_responses.json`

## 🔍 Key Metrics Explained

### Accuracy Metrics
- **Thesis Accuracy**: Percentage of correct initial responses
- **Synthesis Accuracy**: Percentage of correct final responses
- **Dialectical Score**: Improvement from thesis to synthesis (synthesis_acc - thesis_acc)

### Dialectical Quality Metrics
- **Opposition Compliance (OC)**: Quality of antithesis challenges
- **Synthesis Improvement**: Quantified reasoning enhancement
- **Error Correction Rate**: Frequency of thesis error correction in synthesis

## 🎯 Understanding Results

### Positive Dialectical Score
- Indicates model benefits from dialectical reasoning
- Shows improved performance through critical reflection
- Demonstrates effective thesis-antithesis-synthesis process

### Negative Dialectical Score  
- Suggests dialectical process may introduce errors
- May indicate overconfidence or confusion from multiple perspectives
- Important for understanding model limitations

### Neutral Dialectical Score
- Model maintains consistent performance
- May indicate robust initial reasoning or limited dialectical benefits
- Requires deeper analysis of specific question types

## 📋 Analysis Workflow

### Basic Analysis (Automatic)
1. Run evaluation script (`./evaluate-gsm.sh` or `./evaluate-mmlu.sh`)
2. Review `summary_aggregate.json` for key metrics
3. Examine basic comparison charts

### Manual Analysis Options
1. Use the available analysis scripts in `scripts/analysis/`
2. Examine individual question patterns in `all_responses.json`
3. Generate custom final tables with `generate_final_table.py`

## 🔧 Custom Analysis

For custom analysis, key files to examine:
- **`all_responses.json`** - Raw dialectical data
- **`evaluation_results_attempt_1.json`** - Statistical summaries
- **Individual response files** - Detailed question-level analysis

Available analysis scripts:
- `generate_final_table.py` - Final results table generation
- `generate_summary.py` - Summary statistics generation  
- `aggregate_experiments.py` - Cross-experiment aggregation
- `evaluate_reasoning.py` - Dialectical reasoning evaluation
